# Malaysia Labour Market Analysis

## Problem
Graduate and youth unemployment is a major concern for fresh graduates in Malaysia. This project analyses the monthly Labour Force Survey to understand how unemployment differs by state, age group, and over time.

## Data
- Source: OpenDOSM Labour Force Survey (open.dosm.gov.my)
- Coverage: monthly data, [start year] to [end year]
- Raw files are kept unchanged in `data/raw`

## Business Questions
1. How has graduate unemployment changed by state since 2015?
2. Which states have the highest youth unemployment?
3. Did COVID-19 change the trend permanently or temporarily?

## Methods
- Data cleaning and validation with pandas
- Analysis with SQL (PostgreSQL/SQLite)
- Confidence intervals and sampling limitations
- Dashboard built with Streamlit/Power BI
